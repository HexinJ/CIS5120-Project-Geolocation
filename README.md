# Class Attendacne Geolocation Proof of Concept

### Introduction
This repository contains code for a small Expo App built with React Native and JavaScript to test functionalities for realtime location tracking and geofencing. 
This repository is intended to be used as a part of the submission for Assignment 5 of CIS5120 Human Computer Interaction. 

### Location Tracking
The App asks users to enable location sharing, and tracks the user's location in realtime. This allows the longitude and latitude of the user's location be known
so that the App can decide if the user's close enough to a specific location. This is done by using expo-location.

### Geofencing
Geofencing tracks if the user has entered or left a predefined region specified by longitude, latitude, and radius. This allows automation in determining if the 
user is close enough to a specific location to check in. This is also done by using expo-location.
